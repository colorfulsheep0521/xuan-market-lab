# XuanMarket Lab

独立的象数学选股与交易模拟实验。策略以股票行业、名称、代码和历法生成五行、卦象、候选排名、持有周期与交易时辰。

没有券商连接，不下真实订单。历法采用工程近似；实验结果不证明玄学因素具有预测能力。

## 安装

Python 3.9 或以上，在仓库根目录运行：

```sh
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

## 离线合成示例

```sh
python src/make_demo.py
python src/run_natural_account.py --end-date 2024-03-01 --initial-cash 30000
```

示例价格、公司名称及分钟行情全部由代码生成，不包含任何人的账户或交易记录。示例日历仅为工作日序列，不作为真实交易所日历。

## 使用公开行情

准备公开行业标签与不复权行情，日期自行选择：

```sh
python src/prepare_data.py --start-date 2024-01-02 --end-date 2024-03-01
python src/run_natural_account.py --end-date 2024-03-01 --initial-cash 100000
```

第一次全市场下载可能耗时较长。可用 `--codes` 指定公开证券代码缩小范围，也可用 `--labels` 提供公开公司行业CSV。
行情和运行结果仅保存在本地被Git忽略的目录。公开行情下载来自BaoStock，不需要私有账户密钥；可用性由数据源决定。

## 执行约定

- 资金金额可配置，不固定为某个档位；不同本金独立记账，不融资、不从账户外补钱。
- 使用算法当天的历法信号、原排名和组合复评，按各股计划时辰执行，不统一推迟一天。
- 每次买入为100股整数倍；科创板同时满足最低200股。卖出保留适用的零股处理。
- T+1冲突保留原卖出信号；后续逐日重新运行该股玄学持有期与时辰逻辑，寻找新的合法卖点，不强制次日卖出。
- 不额外设置单票比例上限、参与成交量比例、固定等待期限或持仓数量上限。
- 现金、整手、费用、实际停牌/涨跌停及分红送转正常入账。资金不足的买单不强行成交。
- 成交价格使用计划时刻之后第一个五分钟区间开盘价近似；按时间排序，不能用下午卖出的钱提前买早上的股票。
- 五分钟行情没有逐笔盘口或排队信息，不保证真实成交，不额外计盘口滑点。

自然执行入口是 `src/run_natural_account.py`。`run_xuan_lab.py` 中的日线简化回放和 `execution_simulator.py` 中的日线实验仅用于研究对照，不代替默认执行策略。

## 测试

```sh
PYTHONPATH=src python -m unittest discover -s tests -v
```

覆盖资金参数、100股倍数、T+1重新择时、分钟时间顺序、费用、现金、分红、送转与股数守恒。
运行账户还会核对逐笔现金、T+1、股数变化、时间顺序和每日权益；重复运行不会重复成交，历史前缀变化会阻止提交新快照。

## 文件与隐私

本仓库仅提供代码、测试、合成数据生成器和规则文档，不包含个人资料、真实交易流水、账户快照、本机路径、密钥、日志或原项目历史。
`data/`、`outputs/`、日志、环境文件及常见账户数据格式默认忽略；提交前仍应检查 `git diff --cached`。

数据路径：`data/strategy/`、`data/market/`、`data/minute/`。
账户输出：`outputs/accounts/capital_<金额>/latest.json` 指向成功快照。
更换样本或起始日期进行独立实验时，应在新的工作目录运行，以免与已有账户混用。
